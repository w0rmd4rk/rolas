# Rolas: instalación

1. Crea un repositorio público en GitHub (por ejemplo `rolas`) y sube estos 6 archivos a la raíz.
2. En el repo: Settings → Pages → Source: "Deploy from a branch" → rama `main`, carpeta `/ (root)` → Save.
3. En un minuto queda en `https://TU_USUARIO.github.io/rolas/`.
4. Ábrelo en Brave (Android) → menú ⋮ → "Instalar app" / "Agregar a pantalla de inicio".
5. Verifica que Brave Shields estén activos (ícono del león) para bloquear anuncios.

## Buscar por nombre (opcional)
1. Entra a console.cloud.google.com, crea un proyecto y habilita "YouTube Data API v3".
2. Credenciales → Crear credencial → Clave de API.
3. Restringe la clave a "Referentes HTTP" con `https://TU_USUARIO.github.io/*`.
4. Pégala en Rolas → Ajustes.

Sin clave puedes agregar canciones pegando links de YouTube.
Tus playlists se guardan en el navegador; usa Ajustes → Exportar para respaldarlas.
